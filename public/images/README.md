# Images

Drop images here:

- `public/images/profile/me.jpg` — profile photo
- `public/images/profile/hero.png` — temporary project image used by all project cards

Project image paths live in `src/data/portfolio.js`.
When ready, add your real project images anywhere under `public/images/`, then update each `image` value.

Supported formats: jpg, jpeg, png, webp, svg.
If image missing, UI shows placeholder instead of breaking.
