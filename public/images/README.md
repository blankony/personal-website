# Images

Drop images here:

- `public/images/profile/me.jpg` — profile photo
- `public/images/projects/analisis-qos.jpg` — QoS project
- `public/images/projects/indoor-positioning.jpg` — indoor positioning project
- `public/images/projects/obs-countdown.jpg` — OBS countdown project

Supported formats: jpg, jpeg, png, webp, svg.

To change filename, update `image` path in `src/data/portfolio.js`.
If image missing, UI shows placeholder instead of breaking.
